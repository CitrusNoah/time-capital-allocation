# Time Capital Allocation

友人を含む若干名を対象にした、Time Capital Allocationの検証用ランディングページです。

- 三術は、時間配分を捉え直すための三つの物差しとして扱います。
- サイト上で直接課金しません。
- 申込内容の確認後、受付可能な方に個別の決済リンクを案内します。
- 公開前にFormspreeのフォームIDを設定します。受信メールアドレスはHTMLへ記載しません。
- アイコンはMITライセンスのPhosphor Icons regularウェイトをjsDelivr経由で読み込みます。
- 計算エンジン、出生情報、顧客データ、内部検証資料は含みません。

This repository contains only the public static landing-page assets.
